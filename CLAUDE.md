# Работа с этим репозиторием

## Ветки и пуш

Работаем и пушим **прямо в `master`**. Отдельные ветки под задачу не заводим,
pull request не открываем, если об этом не попросили явно.

`master` — то, что деплоится: Vercel собирает каждый клиентский проект и панель
оператора из него. Пуш в `master` — это выкладка в прод у живых клиентов,
поэтому перед пушем прогоняем `npm run typecheck` и `npm test` и не оставляем
сборку сломанной.

## Ловушка: сборка правит файлы под гитом

`npm run build` запускает генератор маршрутов TanStack, и тот переписывает
`src/routeTree.gen.ts`, а заодно чинит путь в мёртвом
`src/routes/admin.instagram.old.tsx` — с `/admin/instagram` (дубль живой
страницы) на `/admin/instagram/old`, разводя 4000-строчный мёртвый файл в
настоящий маршрут админки.

Поэтому после сборки всегда смотрим `git status` и не коммитим эти два файла
заодно с остальным. По-настоящему лечится удалением мёртвого файла.

## Проверки

```bash
npm run typecheck   # должен быть зелёным всегда
npm test            # 19 тестов падают исторически, см. ANALYSIS.md
npm run lint        # красный: ~2100 ошибок prettier, из-за него CI не доходит
                    # до typecheck/build/test — результаты сборки в CI не видны
```
